Acceso Remoto en GnuLinux a través de VNC 💻

Fernando Arias

02 Dec 2018 • 2 min read

Instalación y Configuración

  1. Verificar si se encuentra instalado:
    • sudo rpm -q vnc-server
  2. Si no existe hay que instalar el siguiente paquete:
    • sudo yum install vnc-server

  3. Crear password VNC para usuarios del sistema.
    Una vez logueado el usuario debera ejecutar:

    • vncpasswd
      El comando crea el directorio ~/.vnc y el archivo passwd

      Importante: Agregar una contraseña robusta, porque el algoritmo utilizado es vulnerable.

  4. Para iniciar VNC en una sesión ya establecida es necesario el paquete x11vnc

    • sudo yum install x11vnc

Permitir conexión insegura VNC hacia una sesión abierta

  1. Dentro de la sesión abierta ejecutar lo siguiente:
    • x11vnc -forever -rfbauth ~/.vnc/passwd

Conexión insegura por Cliente VNC

  1. Verificar si se encuentra algún cliente instalado:
    • sudo rpm -q vnc
  2. Si no existe, puedes instalar alguno de los siguiente clientes:
    • sudo yum install vnc ó
    • yum install remmina
  3. Configurar en el cliente la sesión VNC a conectarse.
    • IP del Servidor VNC
    • Puerto de conexion VNC-Server

Agregué la conexión no recomendable para poner en conocimiento que la misma es insegura porque todo el tráfico va en texto plano.

Conexión a través de ssh/x11vnc desde el cliente

  • Iniciar la conexión, a través de SSH desde el cliente: 
ssh -t -L 5900:localhost:5900 usuario@IPdeRed 'x11vnc -localhost -display :0'
  • Configurar el Cliente VNC para localhost.

Consideraciones de Seguridad Informática

He realizado algunas pruebas para agregar SSL al servicio VNC y utilizarla con el cliente VNC Viewer (Real VNC), pero aún tengo algunos errores por lo cual parte de la guía públicada en este post no es segura. Se recomienda hacer uso de VNC a través de ssh/x11vnc

Para añadir mayor seguridad a la conexión VNC es necesario agregar reglas de Iptables ó TCPWrappers para permitir una conexión segregada para determinados equipos. También se puede añadir permisos al servicio sshd para controlar que usuarios pueden conectarse a través de ssh/x11vnc cuando sea necesario.

No se recomienda dejar activo el servicio de VNC y las configuraciones publicadas en este post se debe utilizar unicamente cuando sea necesario.

Si conocen de algún metodo seguro por favor añadirlo en sus comentarios. Agradezco el tiempo de lectura y las sugerencias para mejorar el post.
