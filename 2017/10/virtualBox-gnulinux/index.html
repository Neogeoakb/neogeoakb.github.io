Trabajando con Virtual Box 💻

Fernando Arias

27 Oct 2017 • 3 min read

Virtual Box es una herramienta muy útil para virtualizar varios Sistemas Operativos utilizado para pruebas de todo tipo.

Algo común es que la configuración del BIOS evita virtualizar Sistemas Operativos de 64bits.

Por ello debemos Habilitar la Virtualización en la BIOS, que por lo general esta dentro del Menú Seguridad ó Configuración del Sistema (esto varia dependiendo de la marca de Mainboard), dentro de esos menús buscamos alguna Opción que mencione la Virtualización y la "habilitamos".

Si tienen dudas de como hacerlo pueden visitar el siguiente video que enconté en Youtube, existen muchas guías de como hacerlo y estas varían según la marca de Mainboard.

Instalación

La guia esta echa para usuarios de Gnu-Linux y puntualmente para las Distros de CentOs/RedHat/Fedora que tienen repositorios similares.

Creamos el Repositorio de Virtual Box en:

  • cd /etc/yum.repos.d/
  • vim virtualbox.repo
  • Añadimos el siguiente texto: 
name=Fedora $releasever - $basearch - VirtualBox
baseurl=http://download.virtualbox.org/virtualbox/rpm/fedora/$releasever/$basearch
enabled=1
gpgcheck=1
gpgkey=https://www.virtualbox.org/download/oracle_vbox.asc

Ejecutamos los siguientes comandos: 

wget http://download.virtualbox.org/virtualbox/debian/oracle_vbox.asc
  • rpm --import oracle_vbox.asc
  • yum install VirtualBox

Paquetes dependientes de Virtual Box - VBox_Tools

  • yum update kernel
  • yum install dkms binutils patch
  • yum install gcc make libgomp glibc-headers
  • yum install kernel-headers kernel-devel

La instalación de estos paquetes pueden evitar errores durante la instalación del Virtual Box, o cuando se instalen las VBox_Tools.

Generalmente los errores suceden cuando no coincide la versión del Kernel con la versión del kernel-headers y kernel-devel.
