Usando DotFiles 📝

Fernando Arias

17 Dec 2017 • 1 min read

Instalación

Tmux

  • yum install tmux.x86_64

Instalación Vim

Prerequisitos para vim:
* yum install ctags
* yum install vim.x86_64

Archivos de Configuracion
* vim ~/.tmux.conf
* vim ~/.vimrc

Instalación Zsh

  • yum install zsh
    Clonamos el proyecto de GitHub:
  • git clone git://github.com/robbyrussell/oh-my-zsh.git

Editamos el archivo install.sh, comentamos las siguiente linea.
* #chsh -s $(grep /zsh$ /etc/shells | tail -1)

Ejecutamos el archivo de instalación * bash tools/install.sh

Configuración Manual Dotfiles

Tmux .dotfiles

  • mkdir ~/.dotfiles/tmux
  • cd ~
  • ln -s ~/.dotfiles/tmux/.tmux.conf .

Vim .dotfiles

  • mkdir ~/.dotfiles/vim
  • cp -rp ~/.vimrc ~/.dotfiles/vim/
  • cd ~
  • ln -s ~/.dotfiles/vim/.vimrc .

Zsh .dotfiles

  • mkdir ~/.dotfiles/oh-my-zsh
  • cd ~/.dotfiles/oh-my-zsh

Asignamos el valor a la variable ZSH = ~/.dotfiles/oh-my-zsh

En los archivos:
* templates/zshrc.zsh-template
* tools/install.sh

Configuración Automática Dotfiles

Creamos el directorio .dotfiles
* mkdir ~/.dotfiles
* cd .dotfiles
* git clone user@serverGit:akb_dotfiles.git
* ln -s .dotfiles/vim/.vimrc .vimrc
* ln -s .dotfiles/tmux/.tmux.conf .tmux_conf
* ln -s .dotfiles/oh-my-zsh/.zshrc .zshrc

Instalación Plugins Vim

  • vim .vimrc
  • Dentro de vim Ejecutar el siguiente comando :PlugInstall
  • :bd! > Salir del archivo sin grabarlo en bash

Para entender de mejor manera los archivos .dotfiles, recomiendo revisar los archivos publicados por Makigas en Github.
